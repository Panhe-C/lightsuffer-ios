================================================================================
Resources bundled with FilmPhysics — provenance and changelog
================================================================================

The files in this directory are the upstream spektrafilm data the Swift port
needs, packed into compact binary resources by ``tools/pack_resources.py``.
The script never modifies the upstream checkout; it only reads it.

Upstream: https://github.com/andreavolpato/spektrafilm @ 3bb2c2d
Licence:  CC BY-SA 4.0 (see ``SPEKTRAFILM_LICENSE.txt`` at the repository root
          and ``src/spektrafilm/data/license/SPEKTRAFILM_LICENSE.txt``
          upstream).  The licence requires the changes to the profiles and
          the LUTs to be tracked — this file is that changelog.

--------------------------------------------------------------------------------
resources/spectral/            the packed spectral tables
--------------------------------------------------------------------------------

    irradiance_xy_tc.f16       the hanatos 2025 irradiance spectra
                                192 x 192 x 81 float16, C order (5 971 968 bytes)
                                upstream: src/spektrafilm/data/luts/spectral_upsampling/
                                          irradiance_xy_tc.npy (float16)
                                change:   none — the upstream float16 payload is
                                          copied verbatim (the upstream engine
                                          widens it to double without any loss, so
                                          the port does the same on the fly)

    cmfs_cie1931_2deg.f32      the CIE 1931 2° colour matching functions
                                81 x 3 float32, C order (972 bytes)
                                upstream: spektrafilm.config.STANDARD_OBSERVER_CMFS
                                change:   narrowed from double to float32

    illuminants.f32            the standard illuminant spectra
                                6 x 81 float32, C order (1 944 bytes)
                                rows:     TH-KG3, D55, D50, D65, T, K75P
                                upstream: spektrafilm.model.illuminants.standard_illuminant
                                change:   narrowed from double to float32;
                                          the T (incandescent) and K75P (Kinoton)
                                          rows were added for the Kodak Vision3
                                          200T / 500T and the Kodak 2383 / 2393

    The float32 narrowing costs about 1e-7 relative on the chromaticity of
    the reference illuminant; it is the floor of the colour matrix parity
    (see docs/PORTING.md).

--------------------------------------------------------------------------------
the binary layout
--------------------------------------------------------------------------------

Every ``.f32`` / ``.f16`` file is a *flat* C-order array of little-endian
floats; the shape is the one described above.  The index of the hanatos
spectra is

    spectra[(i * 192 + j) * 81 + wavelength]

i.e. the first axis is the ``tc.x`` grid, the second the ``tc.y`` grid and
the third the wavelength (380…780 nm in 5 nm steps).  The loader is
``Sources/FilmPhysics/Resources.swift``.
