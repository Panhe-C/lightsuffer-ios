# tools — reference fixture generator

`gen_fixtures.py` produces the **reference fixtures** that the Swift port
(`Sources/FilmPhysics`) is validated against.

The fixtures are generated by running the **unmodified upstream Python
engine** (`spektrafilm`, commit `3bb2c2d`), so they are ground truth, not a
re-implementation.

## Regenerate

```bash
/workspace/venv-sf/bin/python tools/gen_fixtures.py
```

Options:

```bash
/workspace/venv-sf/bin/python tools/gen_fixtures.py --out /tmp/fixtures
```

Requirements: the Python virtualenv that has `spektrafilm` installed
(`/workspace/venv-sf`). If `spektrafilm` is not importable, the script falls
back to `SPEKTRAFILM_SRC` (default `/workspace/spektrafilm/src`).

The script never writes outside the output directory and never modifies the
upstream checkout.

## What is captured

The upstream pipeline is a small topology with six taps:

```
rgb_in ──▶ log_e_film ──▶ cmy_film ──▶ log_e_print ──▶ cmy_print ──▶ rgb_out
```

For every parameter case the script runs
`spektrafilm.runtime.pipeline.SimulationPipeline` once per tap
(`process(img, inject="rgb_in", collect=<tap>)`) and stores the raw arrays.

### Files

| File | Content |
|---|---|
| `slice1_common.json` | everything shared by all cases: wavelengths, CMFs, illuminant spectra, colour matrices, the digested film/print profile data, the hanatos2025 tc LUT and the test image |
| `slice1_defaults.json` | case 1 |
| `slice1_camera_ev_plus1.json` | case 2 |
| `slice1_print_exposure_and_filter_shifts.json` | case 3 |
| `slice1_dir_couplers_inactive.json` | case 4 |
| `slice2_common.json` | everything the slice 2 cases share: the spectral sampling, the illuminants, the colour matrices, the CAM16-UCS samples, the two input images and the enlarger data |
| `slice2_defaults.json` | slice 2 case 1 |
| `slice2_srgb_input.json` | slice 2 case 2 |
| `slice2_camera_ev_minus1.json` | slice 2 case 3 |
| `slice2_output_gamut_off.json` | slice 2 case 4 |

Total size is ≈ 1.2 MB (slice 1: ≈ 972 KiB, slice 2: ≈ 232 KiB).

### The slice 2 fixtures

The slice 2 fixtures run the **whole** upstream pipeline, injected at
`rgb_in`, and store **every** tap — `log_e_film` included. They are the
ground truth of the camera stage (the hanatos 2025 spectral upsampling), of
the input / output colour space handling and of the output gamut
compression.

### The cases

| Case | Input | Output gamut compression | What it exercises |
|---|---|---|---|
| `defaults` | `linear_prophoto` | `cam16ucs` | the upstream defaults, end to end |
| `srgb_input` | `srgb_encoded` | `cam16ucs` | an sRGB encoded phone photo (`input_color_space = "sRGB"`, `input_cctf_decoding = True`) |
| `camera_ev_minus1` | `linear_prophoto` | `cam16ucs` | `camera.exposure_compensation_ev = -1.0` (the enlarger re-normalises the print exposure) |
| `output_gamut_off` | `linear_prophoto` | `off` | isolates the CAM16-UCS output compressor |

Every other parameter is the base configuration above (all the spatial and
stochastic effects off, the input gamut compression at the upstream default
`xy`).

### The shared file

`slice2_common.json` carries:

* `spectral` — the wavelengths and the CIE 1931 2° colour matching
  functions;
* `illuminants` — the TH-KG3, D55, D50 and D65 spectra, the scan illuminant
  and its normalisation, and its chromaticity;
* `color` — the reference illuminant chromaticity (D55), the ProPhoto RGB →
  XYZ matrix of the filming stage, the XYZ → sRGB matrix of the scanning
  stage and the sRGB → sRGB matrix of the output transfer function;
* `cam16ucs` — the viewing conditions (`L_A`, `Y_b`), the white point and a
  set of samples with their `Jpab` (the forward model) and their compressed
  sRGB values (the output gamut compressor);
* `input_images` — the two camera images (`linear_prophoto`, `srgb_encoded`);
* `enlarger` — the illuminant of the enlarger and the transmittance of the
  CMY dichroic filters.

The hanatos 2025 tc LUT is the one of `slice1_common.json` (it only depends
on the film sensitivity, the hanatos 2025 adaptation and the input gamut
compression).

## Number format

* All floating point values are rounded to **7 significant digits**.
* `NaN` is written as JSON `null`. Upstream
  (`spektrafilm.utils.conversions.density_to_light`) turns NaN densities into
  zero light transmittance, so `null` means "no contribution".
* Wavelength-indexed arrays are `[wavelength][cmy]`, images are
  `[height][width][3]`.
* The hanatos2025 tc LUT is stored as base64 (little endian float32, C order)
  to keep the file small; its SHA-256 is stored next to it.

## Parameter cases

All cases share the same base configuration (see the `params` block of every
fixture file for the *digested* values that were actually used).

**Base configuration — every spatial and stochastic effect is switched off:**

| Upstream field | Value | Meaning |
|---|---|---|
| `camera.auto_exposure` | `False` | no image-dependent metering |
| `camera.lens_blur_um` | `0.0` | no lens blur |
| `camera.diffusion_filter.active` | `False` | no camera diffusion filter |
| `enlarger.lens_blur` | `0.0` | no enlarger lens blur |
| `enlarger.diffusion_filter.active` | `False` | no enlarger diffusion filter |
| `scanner.lens_blur` | `0.0` | no scanner blur |
| `scanner.unsharp_mask` | `(0.0, 0.0)` | no unsharp mask |
| `scanner.white_correction` / `black_correction` | `False` | no black/white correction |
| `film_render.grain.active` | `False` | no stochastic grain |
| `film_render.halation.active` | `False` | no scatter / halation |
| `film_render.glare.active` | `False` | no film glare |
| `print_render.glare.active` | `False` | no print glare |
| `print_render.density_curves_morph.active` | `False` | no print-curve morph (upstream default) |
| `film_render.dir_couplers.active` | `True` | **kept**: the chemical coupling is part of the film |
| `film_render.dir_couplers.diffusion_size_um` | `0.0` | …but its spatial diffusion is off, so it is per pixel |
| `io.output_gamut_compress.algorithm` | `"off"` | no output gamut compression (diagnostic build) |
| `io.input_gamut_compress` | upstream default | `active=True`, `algorithm="xy"`, `knee=(0.0, 1.0, 6.0)` — kept |
| `io.scan_film` | `False` | print-and-scan, not direct scan |
| `settings.use_enlarger_lut` / `use_scanner_lut` | `False` | exact spectral path, no 3D LUT approximation |

**Cases**

1. `defaults` — the base configuration.
2. `camera_ev_plus1` — `camera.exposure_compensation_ev = +1.0`.
3. `print_exposure_and_filter_shifts` — `enlarger.print_exposure = 1.3`,
   `enlarger.y_filter_shift = +10.0`, `enlarger.m_filter_shift = -5.0`
   (Kodak CC units, added to the neutral CC values that
   `digest_params` reads from the upstream `neutral_print_filters.json`).
4. `dir_couplers_inactive` — `film_render.dir_couplers.active = False`.

## Test image

A deterministic 12×12 linear ProPhoto RGB image:

* row 0 — neutral grey ramp, log spaced `0.002 … 2.0`;
* row 1 — saturated colour patches;
* row 2 — skin-like colour patches;
* rows 3…11 — seeded random block (`numpy.random.default_rng(1234)`), log
  spaced `0.001 … 4.0`.

The image is stored in `slice1_common.json` under `test_image`.

## Digested data

Besides the taps, every case file carries the derived data the Swift port
needs but that is not recoverable from the raw profile JSON:

* `neutral_filters_cc` — the neutral CC filter values after the upstream
  database lookup, plus the shifted values;
* `enlarger.filtered_illuminant_spectrum` — the TH-KG3 illuminant after the
  CC filters;
* `print_balance.density_spectral_midgray` / `…_comp` — the print-balance
  reference computed by the filming stage (and its exposure-compensated
  variant);
* `enlarger.exposure_factor_midgray` / `…_comp` / `exposure_factor_used` —
  the print exposure normalisation factors;
* `print_black_white_reference` — the black/white references used by the
  printing stage;
* `dir_couplers.matrix` and `density_curves_before_couplers` — the DIR
  coupler inhibition matrix and the film density curves *before* the
  couplers are applied;
* `camera_exposure_scale`, `pixel_size_um`.

The shared file carries the digested profile data (log exposure, density
curves, density curve layers, channel/base density, the fitted CDF model),
the illuminant spectra, the CIE 1931 2° CMFs, the colour matrices
(ProPhoto RGB → XYZ(D55), XYZ → sRGB, the sRGB → sRGB matrix used by the
output transfer function) and the hanatos2025 tc LUT.

## Verification

The fixtures were checked against the upstream engine by re-implementing the
stage maths from the fixture contents alone (film development, print exposure,
print development and scanning). Every stage reproduces the upstream taps to
≈ 1e-6, i.e. the rounding floor of the 7-significant-digit format.
